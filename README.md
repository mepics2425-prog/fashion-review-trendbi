# \# 👗 Fashion Review Trend BI

# 

# \### Fashion Data Pipeline \& Quality Monitoring

# 

# 패션 상품의 리뷰 데이터를 수집하고, 데이터 품질을 검증하며, 리뷰 변화와 관측 현황을 분석하는 데이터 파이프라인 및 BI 프로젝트입니다.

# 

# \## 📌 프로젝트 소개

# 

# 패션 상품 데이터를 수집하는 과정에서 발생하는 데이터 누락, 리뷰 수 추출 오류, 카테고리별 관측 편중 문제를 해결하기 위한 프로젝트입니다.

# 

# 데이터를 단순히 수집하는 것에 그치지 않고, \*\*수집 → 검증 → 저장 → 분석 → 시각화 → 운영 모니터링\*\*으로 이어지는 데이터 처리 과정을 다룹니다.

# 

# 이 저장소는 실제 업무에서 경험한 문제 해결 과정을 바탕으로 별도 제작하는 \*\*개인 포트폴리오용 데모 프로젝트\*\*입니다.

# \## 🔍 주요 문제 해결 경험

# 

# \*\*문제 1. 리뷰 수 추출 실패\*\*

# 

# 상품 페이지의 데이터 구조에 따라 리뷰 수를 정확하게 추출하지 못하는 문제가 발생했습니다.

# 

# 이를 해결하기 위해 데이터 구조를 분석하고, JSON-LD 기반 보조 추출 및 결과 검증 방식을 적용했습니다.

# 

# \*\*문제 2. 카테고리별 관측 데이터 편중\*\*

# 

# 일부 카테고리에 관측 데이터가 집중되어 상품군 간 비교에 한계가 발생했습니다.

# 

# 이를 개선하기 위해 카테고리별 균형 관측과 검색어 순환 방식을 설계했습니다.

# 

# \*\*문제 3. 분석 결과의 관측 근거 부족\*\*

# 

# 단순 리뷰 증가량만으로 데이터의 비교 가능성을 판단하기 어려웠습니다.

# 

# 이를 해결하기 위해 관측 날짜 수, 관측 기간, 최근 관측 시점을 활용한 데이터 품질 지표를 설계했습니다.
