## 이번 점검에서 수정한 문제

1. CSV 행의 필드가 누락되면 `AttributeError`가 발생했다. 필수·중복 헤더, 누락·초과 필드, 잘못된 따옴표를 명시적인 입력 오류로 처리한다. 명시적인 빈 리뷰 셀은 계속 null로 허용한다.
2. 검색 결과가 없는데 차트 제목에는 이전 상품이 남았다. 제목을 초기 상태로 바꾸고 선택 컨트롤을 비활성화한다.
3. 로딩 실패 안내에 재시도 수단이 없었다. 재시도 버튼과 실제 복구 흐름을 추가했다.
4. 보조 글자의 가독성을 보완하고 차트의 Y축 자동 범위를 표시했다. 기존 디자인과 레이아웃은 유지했다.
5. 이전 미리보기 3개의 실제 인코딩이 JPEG였으나 확장자는 PNG였다. PNG로 변환하고 재발 방지 형식 검사를 추가했다. 콘텐츠를 보정하거나 화면을 재구성하지 않았다.
6. CSS·JS에 버전 query를 붙여 이전 방문자의 정적 자산 캐시와 구분한다. 환경 파일·개인 키·덤프·캐시의 ignore 규칙을 보완했다.

README는 로컬 Markdown 렌더러로 이미지 3개 로딩과 첫 화면을 확인했다. GitHub 서버 자체의 렌더링을 검증한 것은 아니다. SVG는 브라우저에서 층·화살표·텍스트 위치를 확인했다. 데스크톱·모바일은 뷰포트 캡처를 제공하며 전체 페이지 캡처는 도구에서 실패했다.

## Git 보존

기존 저장소의 HEAD와 추적 상태를 먼저 확인했다. Git이 추적하는 파일은 README이고 나머지 포트폴리오는 미커밋 상태였다. 이번 작업은 해당 파일을 직접 검사하고 필요한 부분만 수정했다. 기존 Git 기록을 초기화하거나 기존 파일을 삭제하지 않았다. Commit·Push·저장소 공개 범위·Pages 설정 변경은 수행하지 않았다.
