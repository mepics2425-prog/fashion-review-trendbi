# Data Quality Strategy

품질 등급은 **관측 이력의 충실도와 비교 가능성을 위한 운영 지표**다. 통계적 신뢰구간, 예측 정확도, 리뷰의 진위나 모집단 대표성을 뜻하지 않는다. UI는 모호한 ‘신뢰도 점수’ 대신 관측 품질이라는 표현을 쓴다.

## 관측과 추출 시도를 구분한다

`review_count = null`은 추출 실패·확인 불가이며 `0`은 검증된 실제 0이다. null 스냅샷은 감사·문제 확인을 위해 보존하지만, 유효 관측 수·날짜 수·최근성·증가량 계산에서는 제외한다. 실패 시각만 최신이라는 이유로 오래된 값을 신선하게 평가하지 않는다.

| 항목 | 공개 데모 정책 |
| --- | --- |
| CSV 구조 | 필수·중복 헤더, 누락·초과 필드, 닫히지 않은 따옴표 검증; 명시적 빈 셀과 빠진 필드를 구분 |
| 상품 식별자 | 가상 `DEMO-001` 형식만 허용 |
| 문자열 | 앞뒤 공백 제거, 연속 공백 축약 |
| 리뷰 수 | 비음수 정수 또는 빈 CSV 필드 → null; 소수·음수·불명 문자열 거부 |
| 시각 | UTC offset 필수, KST(+09:00)로 정규화 |
| 동일 상품·동일 순간 | 동일 레코드는 1개로 축약; 값 충돌 시 전체 생성 실패 |
| 상품 ID 중복 | 정규화 후 동일하면 축약; 메타데이터 충돌 시 실패 |
| 알려지지 않은 상품 ID | 실패 처리, 고아 관측 적재 방지 |
| 미래·기간 밖 관측 | 해당 분석 창에서 제외 |

## 7일 평가 창과 정확한 경계

기준 시각을 `T`라 할 때 `[T − 7×24h, T]`의 **양 끝 포함** 구간에서 유효 관측만 사용한다. 한 상품에 대해 다음을 계산한다.

```text
snapshots     = 고유 유효 관측 시각 수
distinct_dates = KST로 변환한 관측 날짜의 고유 수
first_at      = 최초 유효 관측 시각
last_at       = 마지막 유효 관측 시각
span_hours    = (last_at − first_at)의 실제 경과 시간
age_hours     = (T − last_at)의 실제 경과 시간
```

| 등급 | 모든 조건 충족 |
| --- | --- |
| 반복 관측 | 날짜 ≥ 3, 기간 ≥ 48h, 최근성 ≤ 72h |
| 비교 가능 | 날짜 ≥ 2, 기간 ≥ 24h, 최근성 ≤ 72h, 반복 관측 미달 |
| 추가 관측 필요 | 위 기준 미달 또는 유효 관측 없음 |

같은 날 10번 관측해도 고유 날짜는 1일이다. 자정 직전·직후 관측은 KST 날짜가 2개여도 24시간을 채우지 못하면 비교 가능이 아니다. 경계 판정은 반올림 전 시간으로 하고, 표시값만 소수 둘째 자리로 반올림한다. 유효 관측이 없으면 최초·최근 시각 및 최근성은 null이다.

## 리뷰 트렌드

선택 기간 안의 최초·최종 유효 관측값으로 계산한다. 기간 시작의 값을 보간하거나 기간 바깥의 값을 가져오지 않는다.

```text
delta = last_count − first_count
reviews_per_day = delta / ((last_at − first_at).total_seconds() / 86400)
```

유효 관측이 2개 미만이면 delta·속도는 null이다. 관측이 듬성듬성하면 속도는 **실제 관측 구간의 평균 변화율**이며 순간 속도나 기간 전체의 추정치가 아니다.

계열 내 한 번이라도 감소하면 signed delta는 보존하고 `decrease_detected`로 표시한다. 원인은 리뷰 삭제·수정·추출 오류 등일 수 있어 자동으로 단정하지 않는다. 해당 계열의 속도는 null로 두고 증가 순위·순증 합계에서 제외한다. 중간 감소 후 회복한 계열도 같은 정책이다. 품질 등급과 감소 플래그는 서로 다른 축이다.

화면의 순위·순증 합계는 선택 기간에서 **비교 가능 이상의 관측 기준**을 만족하고 감소가 없는 상품만 포함한다. 합계는 전체 시장 리뷰 증가량이 아니다. 상품 목록에는 짧은 구간의 계산값도 표시하되 7일 품질을 함께 보여준다.

## 커버리지와 모니터링 분모

- **7일 비교 커버리지:** 필터에 해당하는 상품 중 `반복 관측 + 비교 가능` 상품 수 / 필터 상품 수. 분모가 0이면 ‘—’.
- **카테고리 분포:** 카테고리 상품 수와 그중 비교 가능 이상 상품 수.
- **가상 수집 성공률:** 해당 기간 실행의 `Σ succeeded / Σ attempted × 100`. 실행별 성공률의 단순 평균이 아니다.
- 실패 유형 합계는 가상 실행의 `attempted − succeeded`와 같아야 한다.
- 가상 실행 이력은 상품 스냅샷과 별도 fixture다. 실제 수집 결과의 연결 관계를 시뮬레이션하지 않는다.
